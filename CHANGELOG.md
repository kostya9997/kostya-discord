## [1.3.0] - 2026-10-25
### Добавлено
- Интерактивный симулятор веб-камеры для Test mode call: если физическая камера отключена, занята или не найдена в системе, в тестовом режиме автоматически запускается симуляция видеопотока с видоискателем и таймкодом для тестирования UI звонка.
- Гибкий многоуровневый захват камеры (`getCameraStream`): прямой fallback с `video: true`, идеальных ограничений и перебора `videoinput` устройств для максимальной совместимости со всеми драйверами UVC.
- Кнопка «Test mode call» и панель симуляции тестового звонка в панели разработчика WebRTC DevTools (шапка приложения очищена от лишних кнопок).
- Кнопка «Внешность» (🎭) на панели управления звонком и плитки участника для смены гардероба на лету.
- Отображение версий клиента и пира в метриках панели разработчика и бейджах лобби/шапки.
- Инструкции для агентов и разработчиков по версионированию (`AGENTS.md`).
- Конфигурация генератора заметок к релизам GitHub (`.github/release.yml`).

### Изменено
- Оптимизирован запрос медиа-разрешений: при старте приложения/звонка запрашивается исключительно микрофон (`video: false`). Запрос доступа к веб-камере происходит строго по требованию — только при явном клике по кнопке камеры.

### Исправлено
- Исправлена ошибка `Requested device not found`: устранено падение при включении камеры за счет ступенчатого fallback и поддержки режима симуляции камеры.
- Исправлено позиционирование панели управления звонком (`callbar` / `discord-callbar`): панель теперь корректно зафиксирована горизонтально по центру внизу экрана (`position: absolute; bottom: 24px; left: 50%`) и больше не выстраивается в вертикальный столбец слева, сжимая видеосетку.
- Восстановлены утраченные элементы интерфейса в `index.html` и `style.css` (модальное окно выбора внешности, диалог пресетов демонстрации экрана, холст и плавающая панель рисования).
- Исправлено отображение говорящего аватара собеседника в Test mode call (гарантированный рендеринг canvas-потока персонажа поверх статичной заглушки).
- Устранена полосатость фона: видеоплитка и сетка теперь бесшовно сочетаются с фоном холста персонажа (`var(--bg-primary)`).
- Сглажены скругления зелёной рамки речи говорящего (Speaking Ring) через мягкий `box-shadow` без искажения углов `outline`.
- Восстановлена демонстрация экрана с возможностью выбора качества (Эконом, Обычный, Игры 60 FPS) и системного звука.
- Исправлен запуск инструментов рисования поверх экрана (лазерная указка, исчезающие штрихи, маркер, ластик).
- Добавлена мгновенная отрисовка говорящего аватара в окне превью сразу при открытии лобби.
- Исправлено скрытие локальной плитки при отключении своего аватара: при выборе режима «Без аватара» локальное окно больше не исчезает, пользователь всегда видит себя в виде кружка профиля с инициалом и зелёным индикатором речи (Speaking Ring) во время разговора.
- Исправлена работа настройки «Скрыть аватаров собеседников» в Test mode call: чекбокс теперь полноценно переключает между говорящим аватаром и классической карточкой собеседника (кружок с инициалом) как в реальном вызове, так и в симуляторе.
- Добавлена анимация зелёного контура речи Discord для круглых аватаров профиля (.speaking .avatar-circle).
- Опция «Скрыть аватаров и у других собеседников (классический режим для всех)» вынесена во все плашки гардероба (Персонаж, Моё фото, Без аватара) как в лобби, так и в окне смены внешности во время звонка с автоматической синхронизацией состояния.

## [1.2.0] - 2026-10-24
### Добавлено
- Сжатие SDP токенов через библиотеку `sdp-compact` и Gzip для ультра-компактного обмена ключами.
- Интерактивный аудио-реактивный аватар (Lip-sync с анализом микрофона через Web Audio API).
- Гардероб и кастомизация скинов аватара.
- Совместная интерактивная доска (Whiteboard) поверх видеозвонка.
- Аннотации и рисование на расшаренном экране.
- Передача файлов через WebRTC DataChannel с чанкованием по 64 КБ.
- Встроенный P2P текстовый чат с бейджами непрочитанных сообщений.
- Детектор несовпадения версий собеседников: уведомление, если у пира устаревшая версия.
- Панель разработчика (Dev Drawer) с метриками WebRTC, состоянием ICE и онэкранным логом.

### Изменено
- Оптимизирована задержка соединения и убраны лишние задержки `setTimeout`.
- Улучшена обработка отключения и быстрого реконнекта звонка.

### Исправлено
- Проблемы с захватом и синхронизацией аудиопотока при демонстрации экрана.
- Сброс состояния UI при разрыве соединения со стороны собеседника.
